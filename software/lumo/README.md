# Lumo

Lumo es el asistente de Assambl. `lumo-final.html` es su definición de diseño: forma, paleta, los diez estados
(`data-state`) y cuándo se usa cada uno. `lumo.svg` es la marca estática (favicon, avatar).

El componente que usa la aplicación vive en `frontend/src/componentes/lumo/` (`Lumo.tsx` y `lumo.css`). Si se
cambia el diseño acá, se actualiza también ahí.
